# IYK

> IYK provides primitives and apps for building digi-physical (phygital) experiences, connecting physical products and merchandise to blockchain tokens, POAPs, and digital content through NFC chips. The IYK API lets brands and artists chip physical items, verify authentic taps, gate content and rewards, and mint or transfer linked NFTs. Backed by a16z.

## API
- [IYK API Overview](https://docs.iyk.app/api-overview): Core, Modules, and Self-Service POAP endpoints. Base URL https://api.iyk.app; auth via x-iyk-api-key header.
- [Quickstart](https://docs.iyk.app/api-quickstart): Step-by-step integration walkthrough.

## Core endpoints
- [Chips](https://docs.iyk.app/api-core/chips): Register and manage NFC chips (NTAG 424, KONG, ARX HaLo); GET /chips/find validates taps.
- [Chip Groups](https://docs.iyk.app/api-core/chip-groups): Named groupings of chips within a workspace.
- [Items](https://docs.iyk.app/api-core/items): Products/collectibles with contract, media, and variants.
- [Taps / Refs](https://docs.iyk.app/api-core/refs): Single-use, replay-protected tap resolution with linked NFT and POAP data.
- [OTP Codes](https://docs.iyk.app/api-core/otps): One-time passwords for NFT transfers and minting (30-minute TTL).
- [Phygitals](https://docs.iyk.app/api-core/phygitals): Phygital objects combining physical items with digital tokens.

## Modules
